# 🚀 Star Citizen - Limpiador de Caché

Una herramienta sencilla y ligera para **escanear y limpiar la caché de Star Citizen** de forma rápida y segura, sin tener que navegar manualmente por las carpetas del juego.



## ✨ Características

* 🔍 **Escanear carpeta**
  Detecta automáticamente las cachés disponibles dentro de la carpeta de Star Citizen.

* ☑️ **Marcar todo**
  Selecciona todas las cachés encontradas con un solo clic.

* ⬜ **Desmarcar todo**
  Quita rápidamente todas las selecciones.

* 🗑️ **Borrar seleccionados**
  Elimina únicamente las cachés que hayas seleccionado.

* 💥 **Vaciar caché completa**
  Borra todas las cachés detectadas con **un solo clic**.

* 📊 **Información del tamaño**
  Muestra cuánto espacio ocupa cada caché y el tamaño total seleccionado.

* 📝 **Registro de operaciones**
  Incluye un registro donde puedes ver los escaneos y acciones realizadas.

* 📁 **Carpeta configurable**
  Puedes seleccionar manualmente la carpeta donde se encuentra la caché de Star Citizen.

## 📂 Ubicación de la caché

Por defecto, la aplicación utiliza la carpeta local de Star Citizen:

```text
C:\Users\<Usuario>\AppData\Local\Star Citizen
```

La ruta puede cambiarse desde el botón **Examinar...**.

---

## 🧹 ¿Qué hace?

Star Citizen genera archivos de caché que pueden crecer considerablemente con el tiempo.

Esta herramienta permite:

**Escanear → Seleccionar → Limpiar**

sin tener que buscar y eliminar manualmente las carpetas correspondientes.

Por ejemplo, si tienes varias versiones de Star Citizen almacenadas:

```text
Star Citizen
├── starcitizen_(sc-alpha-4.10.0)_...
├── starcitizen_(sc-alpha-4.9.0)_...
└── ...
```

el programa las detecta y muestra su tamaño para que puedas decidir qué eliminar.

---

## ⚡ Vaciar la caché en un clic

Si simplemente quieres limpiar **toda la caché detectada**, puedes utilizar:

> **VACIAR CACHÉ COMPLETA (1 clic)**

Esta opción evita tener que seleccionar manualmente cada elemento.

Si prefieres tener control sobre qué se elimina, puedes seleccionar individualmente las entradas y utilizar:

> **Borrar seleccionados**

---

## 📊 Información del espacio

La aplicación muestra el tamaño de cada elemento encontrado:

```text
☐ starcitizen_(sc-alpha-4.10.0)_...  (1967.96 MB)
☐ starcitizen_(sc-alpha-4.9.0)_...   (1772.26 MB)
```

También se muestra el **tamaño total de los elementos seleccionados** antes de eliminarlos.

---

## 🔒 Seguridad

El programa está diseñado para actuar únicamente sobre los elementos de caché encontrados dentro de la **carpeta base seleccionada**.

Aun así, como con cualquier herramienta de limpieza:

> ⚠️ Comprueba la carpeta seleccionada antes de utilizar las opciones de borrado.

No elimines manualmente otras carpetas si no sabes para qué sirven.

---

## 💻 Requisitos

* Windows
* Star Citizen instalado
* Acceso a la carpeta local de Star Citizen

No es necesario navegar manualmente por `AppData` si utilizas la ruta predeterminada.

---

## 🚀 Uso

1. Abre **Star Citizen - Limpiador de Caché**.
2. Comprueba la **Carpeta base**.
3. Pulsa **Escanear carpeta**.
4. Selecciona las cachés que quieras eliminar.
5. Pulsa **Borrar seleccionados**.

O, si quieres limpiar todo:

1. Pulsa **Escanear carpeta**.
2. Pulsa **Vaciar caché completa (1 clic)**.
3. Confirma la operación si la aplicación lo solicita.
